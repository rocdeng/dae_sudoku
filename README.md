# 找鹅助手

粘贴一张关卡截图，直接告诉你鹅（鸭子）该放在哪些格子上。

## 跑起来

```bash
npm start          # http://localhost:5173
./start.sh         # 或者这个：带 Node / 端口检查
```

打开网页后 `Ctrl + V` 粘贴截图即可，也可以拖图片进去或点右上角选文件。

## 怎么工作的

1. **认棋盘**：按"彩色像素"的行列覆盖率找出棋盘矩形，再用格子之间的白色缝隙切出网格。
2. **认色块**：取每格中间区域的众数颜色，按颜色距离聚类，同色的就是同一个色块区域。
3. **认状态**：格子里的白色像素占比高 → 有标记；同时出现深色像素 → 是已经放好的鹅；只有白色 → 是玩家标的 X。
4. **解**：`每行 / 每列 / 每个色块各一只，且互不相邻（含斜角）`，穷举所有解。规则没歧义时结果就是唯一答案。

识别和求解全部在浏览器本地完成，截图不会上传到任何地方。

## 两种模式

- **全自动**：一次性把整关该放鹅的位置全标出来。
- **推下一步**：一次只标一只，点「下一步」按顺序推进，被你操作的那一格子会闪三下。

截图里已经放好的鹅会以半透明显示，不会被当成待放的位置。

## 测试

```bash
npm test
npx playwright install chromium   # 首次一次，下载 headless 内核
node tools/verify.mjs             # 用 Playwright Chromium 跑一遍真实截图，打印识别结果
```

`tools/verify.mjs` 和 `tools/autoplay/` 使用 Playwright 自带的 Chromium headless 内核（`chrome-headless-shell`），不依赖本机 Edge，也不会在 Dock 里弹图标。
